Ustedes ya saben que la máquina ve números. ¿Podrán enseñarle a reconocer dibujos?</p>

<p style="margin: 0; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 19px; font-weight: bold; line-height: 1.5;"><em>La máquina sabe lo que le mostramos, y nada más.</em></p>

<h2 style="margin: 0 0 8px; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 23px; line-height: 1.3;">Dibujos tramposos</h2>
<p style="margin: 0 0 18px; color: #333333; font-family: Roboto, 'Open Sans', sans-serif; font-size: 16px; line-height: 1.5;">¿Qué dirá la máquina con estos dibujos? Antes de probar, predigan.</p>
<img src="https://enzou.github.io/taller-arte-maquinas/recursos/vc4/dibujos_tramposos.png" alt="Diez dibujos tramposos para poner a prueba el modelo" style="width: 100%; max-width: 900px; height: auto; margin: 0 auto; border-radius: 8px;" /></div><div style="margin: 28px 0; padding: 22px; border: 2px dashed #00a096; border-radius: 10px; background-color: #ffffff; font-family: Roboto, 'Open Sans', sans-serif;">
<h2 style="margin: 0 0 12px; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 23px; line-height: 1.3;">Consigna principal</h2>
<p style="margin: 0 0 18px; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 18px; line-height: 1.6;">Entrenen un modelo con dibujos y pónganlo a prueba. Para cerrar el encargo:</p>
<div style="margin: 0 0 12px; padding: 14px 16px; border-left: 5px solid #007a75; border-radius: 6px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;">Hacemos una <strong>predicción</strong> antes de cada prueba.</p>
</div><div style="margin: 0 0 12px; padding: 14px 16px; border-left: 5px solid #007a75; border-radius: 6px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;">Explicamos <strong>qué mira la máquina</strong> para decidir.</p>
</div></div><h2 style="margin: 32px 0 18px; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 25px; line-height: 1.3; text-align: center;">Pasos para cumplir el encargo</h2>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">1. Jueguen con Quick, Draw!</strong> ¿Alguien le escribió una regla para cada dibujo del mundo?</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">2. Intenten una regla.</strong> Escriban una regla para reconocer una estrella. ¿Funciona con todas?</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">3. Ordenen los datos.</strong> Las carpetas estrella, casa y sol son las etiquetas que la máquina usa para aprender.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">4. Entrenen.</strong> En Teachable Machine, creen tres clases, suban los dibujos de cada carpeta y toquen “Entrenar modelo”.</p>
</div>
<div style="margin: 0 0 28px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">5. Prueben.</strong> Cambien la entrada a “Archivo” y prueben con los dibujos normales y los tramposos.</p>
</div>
