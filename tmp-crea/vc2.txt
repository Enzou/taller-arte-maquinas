<h2 style="margin: 0 0 8px; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 23px; line-height: 1.3;">La obra por dentro</h2>
<p style="margin: 0 0 18px; color: #333333; font-family: Roboto, 'Open Sans', sans-serif; font-size: 16px; line-height: 1.5;">Toquen “Ver dentro” y busquen la bandera, el “por siempre”, la regla y la reacción.</p>
<p style="margin: 0;"><iframe src="https://scratch.mit.edu/projects/1391241076/embed" width="485" height="402" frameborder="0" allowfullscreen=""></iframe></p></div><div style="margin: 28px 0; padding: 22px; border: 2px dashed #00a096; border-radius: 10px; background-color: #ffffff; font-family: Roboto, 'Open Sans', sans-serif;">
<h2 style="margin: 0 0 12px; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 23px; line-height: 1.3;">Consigna principal</h2>
<p style="margin: 0 0 18px; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 18px; line-height: 1.6;">Cambien el umbral de la obra hasta encontrar el número justo. Para cerrar el encargo:</p>
<div style="margin: 0 0 12px; padding: 14px 16px; border-left: 5px solid #007a75; border-radius: 6px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;">La obra <strong>reacciona</strong> con un aplauso.</p>
</div><div style="margin: 0 0 12px; padding: 14px 16px; border-left: 5px solid #007a75; border-radius: 6px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;">La obra <strong>no reacciona</strong> con una tos.</p>
</div></div><h2 style="margin: 32px 0 18px; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 25px; line-height: 1.3; text-align: center;">Pasos para cumplir el encargo</h2>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">1. Abran la plantilla.</strong> Toquen “Ver dentro” y acepten el permiso del micrófono y la cámara.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">2. Lean el programa.</strong> Busquen el evento que lo pone en marcha, la regla y la reacción.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">3. Midan.</strong> Miren cuánto marcan SONIDO y MOVIMIENTO con silencio, voz y aplausos.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">4. Ajusten el umbral.</strong> Cambien solo los números del PASO 1. Prueben con 0, con 100 y busquen el número justo.</p>
</div>
<div style="margin: 0 0 28px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">5. Escriban la regla.</strong> Completen: “Si hay ___, la obra ___”.</p>
</div>
