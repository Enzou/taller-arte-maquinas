<h2 style="margin: 0 0 8px; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 23px; line-height: 1.3;">La pila de pedidos</h2>
<p style="margin: 0 0 18px; color: #333333; font-family: Roboto, 'Open Sans', sans-serif; font-size: 16px; line-height: 1.5;">Lean cada pedido con atención antes de elegir un sello.</p>
<img src="https://enzou.github.io/taller-arte-maquinas/recursos/vc7/tarjetas_de_pedidos.png" alt="Seis tarjetas de pedidos que llegaron al centro cultural" style="width: 100%; max-width: 900px; height: auto; margin: 0 auto; border-radius: 8px;" /></div><div style="margin: 28px 0; padding: 22px; border: 2px dashed #00a096; border-radius: 10px; background-color: #ffffff; font-family: Roboto, 'Open Sans', sans-serif;">
<h2 style="margin: 0 0 12px; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 23px; line-height: 1.3;">Consigna principal</h2>
<p style="margin: 0 0 18px; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 18px; line-height: 1.6;">Elijan un sello para cada pedido y expliquen por qué. Para cerrar el encargo:</p>
<div style="margin: 0 0 12px; padding: 14px 16px; border-left: 5px solid #007a75; border-radius: 6px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;">Usamos <strong>los tres sellos</strong>.</p>
</div><div style="margin: 0 0 12px; padding: 14px 16px; border-left: 5px solid #007a75; border-radius: 6px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;">Cada decisión tiene <strong>una razón</strong>.</p>
</div></div><h2 style="margin: 32px 0 18px; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 25px; line-height: 1.3; text-align: center;">Pasos para cumplir el encargo</h2>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">1. Lean la pila.</strong> Un pedido por vez.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">2. Elijan un sello.</strong> Lo hacemos con IA, Alcanza con una regla o No lo aceptamos. Expliquen por qué.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">3. Pongan a prueba al asistente.</strong> Comparen lo que dice sobre un artista uruguayo con una fuente confiable.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">4. ¿Quién es el artista?</strong> Miren una imagen generada: ¿la hizo la persona o la máquina?</p>
</div>
<div style="margin: 0 0 28px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">5. Imaginen el futuro.</strong> Escriban una nota para quien abra el taller dentro de 20 años.</p>
</div>
