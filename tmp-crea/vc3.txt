<h2 style="margin: 0 0 8px; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 23px; line-height: 1.3;">El dibujo que llegó</h2>
<p style="margin: 0 0 18px; color: #333333; font-family: Roboto, 'Open Sans', sans-serif; font-size: 16px; line-height: 1.5;">Así llegó el dibujo de Valentina. ¿Ven algo?</p>
<img src="https://enzou.github.io/taller-arte-maquinas/recursos/vc3/dibujo_en_numeros.png" alt="El dibujo de Valentina convertido en números" style="width: 100%; max-width: 760px; height: auto; margin: 0 auto; border-radius: 8px;" /></div><div style="margin: 28px 0; padding: 22px; border: 2px dashed #00a096; border-radius: 10px; background-color: #ffffff; font-family: Roboto, 'Open Sans', sans-serif;">
<h2 style="margin: 0 0 12px; color: #007a75; font-family: Roboto, 'Open Sans', sans-serif; font-size: 23px; line-height: 1.3;">Consigna principal</h2>
<p style="margin: 0 0 18px; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 18px; line-height: 1.6;">Pinten entre todos el dibujo a partir de sus números. Para cerrar el encargo:</p>
<div style="margin: 0 0 12px; padding: 14px 16px; border-left: 5px solid #007a75; border-radius: 6px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;">Cada número se convierte en <strong>su color</strong>.</p>
</div><div style="margin: 0 0 12px; padding: 14px 16px; border-left: 5px solid #007a75; border-radius: 6px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;">Descubrimos <strong>qué dibujo es</strong>.</p>
</div></div><h2 style="margin: 32px 0 18px; color: #000000; font-family: Roboto, 'Open Sans', sans-serif; font-size: 25px; line-height: 1.3; text-align: center;">Pasos para cumplir el encargo</h2>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">1. Miren la hoja 1.</strong> Solo hay números. ¿Ven algún dibujo?</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">2. Miren la paleta.</strong> En la hoja 5, cada número es un color.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">3. Pinten sus filas.</strong> Cada grupo copia sus filas en la hoja 2 y la celda se pinta sola.</p>
</div>
<div style="margin: 0 0 12px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">4. Descubran el dibujo.</strong> Comparen con la hoja 3: ¿qué es?</p>
</div>
<div style="margin: 0 0 28px; padding: 17px 20px; border-radius: 10px; background-color: #f0faf9; font-family: Roboto, 'Open Sans', sans-serif;">
<p style="margin: 0; font-family: Roboto, 'Open Sans', sans-serif; font-size: 17px; line-height: 1.5;"><strong style="color: #007a75;">5. Prueben con menos cuadritos.</strong> En la hoja 4 hay 64 cuadritos: ¿sigue siendo una manzana?</p>
</div>
